# Confiq v2

Современная панель управления VPN-конфигурациями с разделёнными **Backend** и **Frontend**.

Проект основан на оригинальном **Confiq** и является его переработанной версией с новым интерфейсом, новой архитектурой и дополнительными возможностями.

---

## 📝 Примечание

Confiq — это универсальный менеджер VPN-конфигураций с поддержкой различных типов конфигураций и различных API.

В оригинальном проекте реализована интеграция с Cloudflare API для создания WARP-конфигураций.

Данная версия сохраняет совместимость с концепцией оригинального проекта, но полностью переработана с точки зрения архитектуры и пользовательского интерфейса.

---

## ⚠️ Важная информация

Автор данного репозитория **не связан** с компанией Cloudflare.

Использование публичного API Cloudflare показано исключительно как пример интеграции.

# 📦 Быстрый запуск

## Клонирование

```bash
git clone https://github.com/verkholantsevda/confiq-v2.git

cd confiq-v2
```

---

## Настройка

Создайте файл окружения Backend.

```bash
cp backend/.env.example backend/.env
```

При необходимости измените настройки.

---

## Сборка

```bash
docker compose build
```

---

## Запуск

```bash
docker compose up -d
```

---

При первом запуске приложение автоматически:

- создаст каталог базы данных;
- создаст SQLite базу данных;
- создаст структуру таблиц;
- выполнит необходимые миграции;
- запустит Backend;
- запустит Frontend;
- запустит Nginx.

---

# 💻 Локальная разработка

### Backend

```bash
cd backend

go run ./cmd/server
```

---

### Frontend

```bash
cd frontend

npm install

npm run dev
```

# 📚 Использование

## Администратор

1. Войдите в систему.
2. Создайте типы конфигураций.
3. Создайте Endpoint.
4. Создайте пользователей.
5. При необходимости создайте группы.
6. Просматривайте и управляйте всеми конфигурациями.

---

## Пользователь

1. Войдите в систему.
2. Создайте конфигурацию.
3. Просмотрите QR Code.
4. Скачайте конфигурацию.
5. Используйте её в VPN-клиенте.

# 👥 Группы пользователей

Поддерживается разграничение доступа к Endpoint.

Каждый пользователь может принадлежать определённой группе.

Администратор определяет, какие Endpoint доступны каждой группе пользователей.
